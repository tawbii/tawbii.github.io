About

I'm Ali, a software engineering student at 42 Beirut. The 42 curriculum is project-based and peer-reviewed, so everything above was built from scratch: no frameworks for the low-level work, and a strict coding standard throughout.

I enjoy the parts of software that are usually hidden: how a shell runs a pipeline, how a server handles many clients from a single thread, how a renderer turns a grid into a 3D scene. I also like leading a team project end to end, from architecture decisions to review.
